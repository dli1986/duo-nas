# export-photos/

RAW → optimized WebP/AVIF thumbnail pipeline. Thumbnails get uploaded to Cloudflare R2 for the public site to display (gallery-style, like maxrivephotography.com/pages/gallery) — originals stay local only.

No "download original" API is planned — the NAS is private, there's no need to expose a download path to site visitors.

Nothing scripted here yet.

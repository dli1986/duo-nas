# export-music/

Pulls track metadata from the public, free APIs (MusicBrainz, Discogs, ListenBrainz) for songs in the personal catalog, and writes `content/music/*.mdx` files into the `duo-li` repo (same frontmatter pattern as `content/knowledge`/`content/reading`).

Catalog entries here are metadata-only by design — they reflect what the owner is interested in/appreciates, and don't require a matching locally-acquired audio file. When a matching file does exist in `../../music/`, that's a bonus, not a requirement.

Nothing scripted here yet.
